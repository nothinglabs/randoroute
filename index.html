Routing settings

Limits

Minimum shoulder is the width required on faster roads. Max acceptable speed without shoulder lets slower roads pass even where shoulder data is missing. Never allow roads faster than makes roads above the selected speed fail; “no cutoff” leaves the shoulder rule in charge.

Options

Allow freeway as last resort permits a freeway only when the network otherwise has no route; it still fails the rules. Fail if no complete safe route found returns no route instead of showing an unavoidable failing segment. Unknown shoulder treated as 0 ft requires fast roads to prove an adequate shoulder. Try online place search adds a manual online lookup button to Start and End search; local search remains available, and the typed query is sent only when that button is pressed.

How the router uses them

Direct is quickest, Balanced avoids bad roads when the detour is reasonable, and Low-stress detours further to avoid failures. Designated bike routes and trails are strongly preferred when that option is on.
